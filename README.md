EXPERIMENT 2.2: 

CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING 

AIM: 

To create a 3D model from the given isometric drawing using fusion 360 tool. 

REQUIREMENTS:

1. Autodesk fusion 360 
2. Windows 10 
3. 16 GB of RAM (integrated graphics recommend 1 GB or more) 
4. 2.5 Mbps or faster download; 500 Kbps or faster upload

STEP-1: Select the Sketch Plane 
Select the TOP (XY) Plane.

STEP-2: Create a Sketch 
1. Select Sketch → Rectangle → Center Rectangle.
2. Hover over the origin (centre) of the sketch until the cursor snaps to it. 
3. Click once to begin placing the rectangle. 
4. Press the Tab key and enter the values 56 mm and 18 mm for width and height, respectively. 
5. Select Sketch → Arc → Center Point Arc. 
6. Select the required centre and both endpoints of the arc.
7. Press Tab and enter the radius as 18 mm.
8. Select Sketch → Circle → Center Point 
Circle.
9. Select the required centre point. 
10. Press Tab and enter the diameter as 16 mm.
11. Click to place the circle. 
12. Click Finish Sketch.

STEP-3: Extrude Sketch in XY Plane 
1. Select Extrude. 
2. Select the sketch profile. 
3. Enter the extrusion distance as 8 mm. 
4. Press Enter to accept the value.

STEP-4: Start the Sketch Command 
Select Sketch → Create Sketch. 

STEP-5: Select the Sketch Plane 
Select the TOP SURFACE of the 3D block.

STEP-6: Create a Rectangle 
1. Select Sketch → Rectangle → Center 
Rectangle.
2. Hover over the origin until the cursor snaps to it.
3. Click once to begin placing the rectangle. 
4. Press Tab and enter the values 40 mm and 10 mm for width and height, respectively. 
5. Click to place the rectangle. 
6. Click Finish Sketch.
   
STEP-7: Extrude Rectangle 
1. Select Extrude.
2. Select the rectangle sketch profile. 
3. Enter the extrusion distance as 32 mm. 
4. Press Enter to accept the value.
   
STEP-8: Create a Triangle 
1. Select Sketch → Triangle → Center Triangle. 2. Hover over the origin until the cursor snaps to it. 3. Click once to begin placing the triangle. 
4. Press Tab and enter the values 32 mm and 12 mm for width and height, respectively. 
5. Click to place the triangle. 
6. Click Finish Sketch.
   
STEP-9: Extrude Triangle 
1. Select Extrude. 
2. Select the triangle sketch profile. 
3. Set the extrusion distance to 6 mm in both directions. 4. Press Enter to accept the value.
    
STEP-10: Create a Polygon 
1. Select Sketch → Polygon → Circumscribed Polygon. 2. Hover over the required origin until the cursor snaps to it. 3. Click once to begin placing the polygon. 
4. Press Tab and enter the values 40 mm and 30 mm for width and height, respectively. 
5. Set the number of sides to 3 as specified. 
6. Click to place the polygon. 
7. Click Finish Sketch.
   
STEP-11: Extrude Polygon
1. Select Extrude. 
2. Select the polygon sketch profile. 
3. Enter the extrusion distance as 10 mm. 
4. Press Enter to accept the value.
   
STEP-12: Create a Circle 
1. Select Sketch → Circle → Center Point Circle. 2. Hover over the required origin at the polygon end until the cursor snaps to it. 
3. Click once to begin placing the circle. 
4. Enter the inner and outer diameter values as specified: 30 mm and 20 mm. 
5. Click to place the circle. 
6. Click Finish Sketch.
   
STEP-13: Extrude Circle 
1. Select Extrude. 
2. Select the circular sketch profile. 
3. Set the extrusion distance to 10 mm in both directions. 4. Press Enter to accept the value.
